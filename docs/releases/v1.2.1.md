## English

**Install:** `bash install.sh` (update: `bash install.sh --update`). See the
[install guide](https://github.com/wgltony/U60Pro-OpenUI/blob/main/docs/INSTALL.md).

- **Clash works out of the box**: the release now includes the pinned Clash core `mihomo`
  (the same build CI tests), and `install.sh` installs it with its geo data and the lpac
  eSIM tool. 1.2.0 installed only the agent, dashboard, touchscreen and WireGuard tool.
- **Windows update**: 1.2.0's `deploy-windows.cmd` looked for a release named `v1.2` and
  failed; 1.2.1's release name matches its version and includes the `mihomo` file it needs.
- **README**: screenshots and animations of the dashboard and touchscreen (all demo data),
  corrected and completed feature descriptions.
- The demo Tailscale exit node now has a generic name.

**Assets:** `zte-agent`, `dashboard-dist.tar.gz`, `openui-screen` (GPL-3.0-or-later, source
in `screen/`), `lpac` (AGPL-3.0 / LGPL-2.1, see `licenses/lpac/`), `mihomo` (GPL-3.0,
source at github.com/chen08209/Clash.Meta plus `scripts/mihomo-patches/`), `sha256sums.txt`.

# v1.2.6 — Tailscale beside Clash and WireGuard / Tailscale 与 Clash、WireGuard 同时运行

简体中文 · English

## 简体中文

**入口：** 已有安装更新使用 `bash install.sh --update --release v1.2.6`；首次安装见 [本版本安装教程](https://github.com/wgltony/U60Pro-OpenUI/blob/v1.2.6/docs/INSTALL.zh.md)。本版本改动 agent、触摸屏与网页，安装流程与 v1.2.5 相同。

1. **未使用出口节点时 Tailscale 可与 Clash 或 WireGuard 同时开启：** 以前 Tailscale 模式与 Clash、WireGuard 互斥，开启任何一个都会关掉另外两个。Tailscale 只有在使用出口节点时才接管上网流量；不用出口节点时，它的流量标记与路由表和 Clash、WireGuard 互不重叠。现在只有选了出口节点才互斥：在 Tailscale 页连接时不再关闭 Clash/WireGuard，开启 Clash/WireGuard 时也不再断开 Tailscale。
2. **仍然互斥的情况：** 选择出口节点时会关闭 Clash 和 WireGuard（设置保留）；在“当前代理”中明确选择 Tailscale 时，仍只保留 Tailscale。
3. **界面提示：** 网页与触摸屏代理页在 Tailscale 同时在线时显示“Tailscale 同时保持连接（未使用出口节点）”。各确认框按是否使用出口节点说明会关闭什么、保留什么。网页上只要 Tailscale 已连接即可选择出口节点，不必先切换到 Tailscale 模式。
4. **兼容性：** 代理状态新增 `alongside`，Tailscale 摘要新增 `exclusive`；触摸屏状态记录 B 末尾新增两个字段。触摸屏遇到旧版 agent 的记录时按互斥处理。

**验证范围：**
- agent 305 项单元测试在实机（U60 Pro，B31）上通过；触摸屏全部自测在本机预览中通过（含新的保留与同时在线画面）；网页 53 项测试、构建、lint、i18n、API 契约与隐私检查通过。
- 实机上验证了：Tailscale 未使用出口节点时开启 Clash，Clash 运行并连接，Tailscale 保持在线超过一分钟、配置未被改动，经 tailnet 新建的 SSH 与网页面板连接正常；随后关闭 Clash，规则被移除。部署方式是替换组件并保留备份，不是经 `install.sh` 全新安装。
- **未在实机验证：** 选择出口节点时自动关闭 Clash/WireGuard 的流程（由单元测试覆盖）。
- **已知限制：** 经 Clash 或 WireGuard 上网的局域网设备不能访问 tailnet 的 100.x 地址。

## English

**Entry point:** update an existing installation with `bash install.sh --update --release v1.2.6`; for first installs see the [versioned install guide](https://github.com/wgltony/U60Pro-OpenUI/blob/v1.2.6/docs/INSTALL.md). This release changes the agent, the touchscreen and the web panel; installation is the same as v1.2.5.

1. **Tailscale without an exit node runs beside Clash or WireGuard:** Tailscale mode used to exclude Clash and WireGuard, so turning any of them on turned the others off. Tailscale only takes over internet traffic through an exit node; without one, its packet marks and routing tables do not overlap Clash's or WireGuard's. They now exclude each other only when an exit node is selected: connecting from the Tailscale page leaves Clash/WireGuard running, and turning Clash/WireGuard on no longer takes Tailscale down.
2. **Still exclusive:** selecting an exit node turns Clash and WireGuard off (their settings are kept), and choosing Tailscale in the proxy selector still makes it the only backend.
3. **UI:** the web and touchscreen proxy pages say when Tailscale stays connected alongside (no exit node). Confirmations say what turns off and what stays on, depending on the exit node. On the web, an exit node can be chosen whenever Tailscale is connected, without switching to Tailscale mode first.
4. **Compatibility:** proxy status gains `alongside` and the Tailscale summary gains `exclusive`; the touchscreen's B status record gains two trailing fields. The touchscreen treats a record from an older agent as exclusive.

**Validation boundary:**
- All 305 agent unit tests passed on a real U60 Pro (B31). All touchscreen self-tests passed in the native preview, including the new stays-on and alongside screens. The 53 web tests, build, lint, i18n, API contract and privacy checks passed.
- On the device we checked: with Tailscale connected and no exit node, Clash turned on, ran and connected while Tailscale stayed online for over a minute with its settings unchanged, and new tailnet SSH and dashboard connections worked; Clash was then turned off and its rule removed. Deployment replaced components with a backup kept; it was not a fresh `install.sh` installation.
- **Not checked on the device:** selecting an exit node and Clash/WireGuard turning off as a result (covered by unit tests).
- **Known limitation:** LAN devices that go out through Clash or WireGuard cannot reach tailnet 100.x addresses.

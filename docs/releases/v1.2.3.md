# v1.2.3 — Custom TTL, accurate live speed and a speed chart / 自定义 TTL、准确实时速率与速率曲线

简体中文 · English

## 简体中文

**入口：** 已有安装更新使用 `bash install.sh --update --release v1.2.3`；首次安装见 [本版本安装教程](https://github.com/wgltony/U60Pro-OpenUI/blob/v1.2.3/docs/INSTALL.zh.md)。本版本只改 agent、触摸屏与网页，安装流程与 v1.2.2 相同。

1. **TTL 预设与自定义：** 网页「蜂窝 → TTL」提供 65（推荐）、64（标准）、128（Windows）、117（部分运营商）四个预设，一点即生效；也可输入 1–255 的自定义值。触摸屏「USB 与 TTL」页同样提供关 / 64 / 65 / 117 / 128 预设，以及 −/+ 调值后「设置」的自定义方式。agent 现在接受任意 1–255，超出范围返回 `Invalid TTL`。
2. **实时速率准确：** 热点转发流量由高通 IPA 硬件加速，绕过 `rmnet` 网卡计数，旧版因此严重低估（测速 350+ Mbps 时只显示约 16 Mbps）。现在优先读取 modem 自身的 WWAN 计数（`zwrt_data get_wwandst`），它包含硬件加速的流量；读取失败才回退到 `rmnet_data0`。旧版把 `rmnet_data0` 与 `rmnet_ipa0` 相加造成的重复计数也已修正。
3. **信号页速率曲线：** 触摸屏「信号」页新增最近 2 分钟的速率曲线（每 2 秒一个点，绿色为下载、蓝色为上传，刻度按峰值自动取 1/2/5 倍），「实时速率」一行也改为约 2 秒更新。数据来自已有的每秒测速，不增加额外读取；只有菜单中有「信号」页时才发送，只有停在该页时才重绘。

**验证范围：** agent 249 项单元测试在实机（U60 Pro，B31）上通过；触摸屏全部自测在本机预览中通过；网页构建、lint 与 i18n 检查通过。实机上验证了 TTL 设置 / 恢复 / 越界拒绝、热点与本机下载时的速率读数（与 modem 计数和 curl 结果一致），以及速率曲线随持续下载变化。部署方式是替换组件并保留备份，不是经 `install.sh` 全新安装。约 2 秒以内的短暂突发可能不在曲线上出现，因为 modem 的速率读数本身略有延迟。

## English

**Entry point:** update an existing installation with `bash install.sh --update --release v1.2.3`; for first installs see the [versioned install guide](https://github.com/wgltony/U60Pro-OpenUI/blob/v1.2.3/docs/INSTALL.md). This release changes only the agent, the touchscreen and the web panel; installation is the same as v1.2.2.

1. **TTL presets and custom values:** the web panel's Cellular → TTL offers four one-tap presets: 65 (recommended), 64 (standard), 128 (Windows) and 117 (some carriers). It also takes any custom value from 1 to 255. The touchscreen's USB & TTL page has Off / 64 / 65 / 117 / 128 presets plus a −/+ stepper with Set. The agent now accepts any 1–255 and answers `Invalid TTL` outside that range.
2. **Accurate live speed:** hotspot traffic is forwarded by Qualcomm IPA hardware offload, which bypasses the `rmnet` interface counters. Older builds therefore badly undercounted it, showing about 16 Mbps during a 350+ Mbps speed test. The agent now reads the modem's own WWAN counters (`zwrt_data get_wwandst`), which include offloaded traffic. It falls back to `rmnet_data0` only when that read fails. The double counting from summing `rmnet_data0` and `rmnet_ipa0` is also fixed.
3. **Speed chart on the Signal page:** the touchscreen's Signal page shows the last two minutes of throughput.
   - One point every 2 s: green for download, blue for upload.
   - The scale is a 1/2/5 step above the peak.
   - The Speed row now updates about every 2 s.
   - The chart reuses the existing once-a-second speed sampler, so it adds no reads.
   - The agent sends it only when the Signal page is in the menu, and the screen redraws it only while that page is open.

**Validation boundary:**
- All 249 agent unit tests passed on a real U60 Pro (B31). All touchscreen self-tests passed in the native preview. The web build, lint and i18n checks passed.
- On the device we checked TTL set, restore and out-of-range rejection. Live speed during hotspot and on-device downloads matched the modem counters and curl. The chart followed a sustained download.
- Deployment replaced components with a backup kept; it was not a fresh `install.sh` installation.
- Bursts shorter than about 2 s may not appear on the chart, because the modem's own speed reading lags slightly.

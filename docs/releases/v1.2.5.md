# v1.2.5 — Relay without a SIM, carrier on the touchscreen and APN in use / 无 SIM 卡中继、触摸屏运营商显示与实际使用的 APN

简体中文 · English

## 简体中文

**入口：** 已有安装更新使用 `bash install.sh --update --release v1.2.5`；首次安装见 [本版本安装教程](https://github.com/wgltony/U60Pro-OpenUI/blob/v1.2.5/docs/INSTALL.zh.md)。本版本改动 agent、触摸屏与网页，安装流程与 v1.2.4 相同。

1. **无 SIM 卡时 Tailscale 经中继正常连接：** tailscaled 自己的流量带有标记，只查 main/default 路由表，查不到就被丢弃；而中继的默认路由在它自己的路由表里。有 SIM 卡时 main 表还有蜂窝路由，拔卡后 Tailscale 就完全离线。中继在线时现在会为这类流量加上与其他流量相同的“先 main、再中继”两条规则（优先级 5207/5208），中继断开时撤掉。
2. **无 SIM 卡时路由器自身的 DNS：** 系统的 DNS 列表只由蜂窝连接填写，拔卡后为空，路由器自己（Clash 订阅、Cloudflare 优选、对时、Tailscale）无法解析域名。中继在线且列表为空时，填入中继网络的 DNS 并打上标记；断开时只清除自己写入的内容，有 SIM 卡时系统填写的列表不会被改动。
3. **无 SIM 卡不再显示信号：** 没卡时 modem 仍为紧急呼叫驻留在某个小区并报告信号强度。现在会读取 SIM 状态，触摸屏顶部、信号格、信号页与网页顶栏、首页、信号页都显示“无 SIM 卡”，不再显示数值。
4. **触摸屏顶部显示运营商：** 主界面状态卡用运营商名称（如 T-Mobile）加四格信号代替 “ENDC -108 dBm”；信号页的数值保持不变。
5. **触摸屏数据不再因时钟跳变而停住：** 本固件的系统时钟会跳变数小时（运营商下发的本地时间与固件自带对时使用的 UTC+8 之间）。时钟往回跳后，触摸屏的信号、Wi-Fi、电池和设备列表最长会停止更新约 12 小时。刷新间隔现在使用单调时钟，触摸屏切换 USB 模式的等待也是如此。
6. **APN 显示实际使用的配置：** 自动模式下，APN 页曾把手动模式的出厂选项（Verizon）标为“已激活”，即使插的是 T-Mobile 卡。现在显示实际拨号所用的 APN（“使用中”），“已激活”只在手动模式下出现，否则标为“手动模式所选”。

**验证范围：**
- agent 303 项单元测试在实机（U60 Pro，B31）上通过；触摸屏全部自测在本机预览中通过（含无 SIM 卡与运营商画面）；网页 53 项测试、构建、lint、i18n、API 契约与隐私检查通过。
- 实机上验证了：无 SIM 卡开中继时 Tailscale 在线（UDP 与 IPv4 可用）、路由器自身可解析域名、状态记录中信号数值为空且标记为无卡；插卡时顶部记录为 T-Mobile；自动模式下 APN 显示实际使用的配置。部署方式是替换组件并保留备份，不是经 `install.sh` 全新安装。
- **未解决：** 无 SIM 卡时系统时钟跳到 UTC+8 的具体来源尚未抓到；本版本只让 agent 与触摸屏不再受时钟跳变影响，没有改动固件的时间设置。

## English

**Entry point:** update an existing installation with `bash install.sh --update --release v1.2.5`; for first installs see the [versioned install guide](https://github.com/wgltony/U60Pro-OpenUI/blob/v1.2.5/docs/INSTALL.md). This release changes the agent, the touchscreen and the web panel; installation is the same as v1.2.4.

1. **Tailscale over the relay without a SIM:** tailscaled marks its own packets and lets them see only the main and default tables before an unreachable rule, while the relay's default route lives in its own table. With a SIM, main still had the cellular route; without one Tailscale was offline behind an online relay. While online, the relay now adds the same main-then-uplink pair for that mark (priorities 5207/5208) and removes it when it goes offline.
2. **Router DNS without a SIM:** the router's resolver list is filled only from the cellular link, so without a SIM it was empty and the router itself (Clash subscriptions, the Cloudflare optimizer, time sync, Tailscale) could not resolve names. While the relay is online, an empty list gets the relay network's resolver, tagged so going offline clears only that entry; a list the firmware filled is never touched.
3. **No signal shown without a SIM:** with an empty tray the modem still camps on a cell for emergency calls and reports a level. The SIM state is now read, and the touchscreen's top bar, bars and Signal page, plus the web header, Home and Signal pages, show No SIM instead of figures.
4. **Carrier on the touchscreen:** the main menu's status card shows the carrier name (e.g. T-Mobile) with four signal bars instead of "ENDC -108 dBm"; the Signal page keeps the figures.
5. **Touchscreen data no longer freezes after a clock step:** this firmware's wall clock steps by hours (carrier local time vs its own time sync at UTC+8). After a backward step the touchscreen's signal, Wi-Fi, battery and device list could stop updating for up to about 12 hours. Refresh intervals now use the monotonic clock, as does the touchscreen's USB mode switch wait.
6. **APN page shows the APN in use:** in automatic mode the page marked the Manual-mode factory choice (Verizon) as Active even with a T-Mobile SIM. It now shows the APN actually dialed ("In use"); the Active badge appears only in Manual mode, otherwise "Manual mode choice".

**Validation boundary:**
- All 303 agent unit tests passed on a real U60 Pro (B31). All touchscreen self-tests passed in the native preview, including the No SIM and carrier screens. The 53 web tests, build, lint, i18n, API contract and privacy checks passed.
- On the device we checked, with no SIM and the relay on: Tailscale online (UDP and IPv4), the router resolving names, and the status record carrying empty figures with the SIM marked absent. With a SIM, the top record carried T-Mobile, and in automatic mode the APN page showed the APN in use. Deployment replaced components with a backup kept; it was not a fresh `install.sh` installation.
- **Open:** the exact source of the clock stepping to UTC+8 without a SIM has not been captured. This release only makes the agent and touchscreen tolerate clock steps; it does not change the firmware's time settings.

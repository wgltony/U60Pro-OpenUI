## 简体中文

1.2.0 是 [acloudpeng/U60Pro-OpenUI](https://github.com/acloudpeng/U60Pro-OpenUI) 1.1.4 的分支版本，
新增一条命令安装，以及下面这些功能。只在 MU5250 / `MU5250_HW1.0` / CN B31 上测试过。

**安装：** `bash install.sh`（更新：`bash install.sh --update`）。见 [安装教程](https://github.com/wgltony/U60Pro-OpenUI/blob/main/docs/INSTALL.zh.md)。

- **一条命令安装**：检查电脑、下载并校验本发布的文件，设备锁定时用上游的解锁流程开启 ADB，
  然后在一次可回滚的部署里装好 agent、网页、触摸屏、WireGuard 工具和可选的 Tailscale。
- **Tailscale**：网页上登录（登录链接或认证密钥）和退出；Tailscale 模式（出口节点）；
  远程管理（子网路由，可与 Clash / WireGuard 同时使用）。
- **设置向导**：Clash、WireGuard、Tailscale 各有分步向导。
- **无线中继**：自动暂停与上游同频段的热点；触摸屏键盘。
- **Wi-Fi 客户端**：网页和触摸屏上拉黑 / 解除拉黑，按设备名识别随机 MAC；发射功率。
- **USB**：USB 网络共享开关；RNDIS / ECM 模式。
- **路由器日志**：中继、Tailscale、拉黑事件，在 **系统 → 工具** 查看。
- **部署**：控制台开机自启（以前只有加 `--harden` 时才会），新文件纳入回滚快照。

## English

1.2.0 is a fork of [acloudpeng/U60Pro-OpenUI](https://github.com/acloudpeng/U60Pro-OpenUI) 1.1.4
with a one-command install and the features below. Tested only on MU5250 /
`MU5250_HW1.0` / CN B31.

**Install:** `bash install.sh` (update: `bash install.sh --update`). See the
[install guide](https://github.com/wgltony/U60Pro-OpenUI/blob/main/docs/INSTALL.md).

- **One-command install**: checks the computer, downloads and verifies this release,
  enables ADB with upstream's unlock when the device is locked, then installs the agent,
  dashboard, touchscreen UI, WireGuard tool and optional Tailscale in one deployment that
  rolls back on failure.
- **Tailscale**: sign in on the web page (link or auth key) and sign out; Tailscale mode
  with an exit node; remote management (a subnet route, alongside Clash or WireGuard).
- **Setup guides** for Clash, WireGuard and Tailscale.
- **Wi-Fi relay**: pauses the hotspot on the upstream's band; on-screen keyboard.
- **Wi-Fi clients**: block / unblock on the web and the touchscreen, name matching for
  random MACs; transmit power.
- **USB**: USB LAN switch; RNDIS / ECM modes.
- **Router log**: relay, Tailscale and blocklist events under **System → Tools**.
- **Deployment**: the dashboard starts at boot (before, only `--harden` added that); new
  files are covered by the rollback snapshot.

**Assets:** `zte-agent`, `dashboard-dist.tar.gz`, `openui-screen` (GPL-3.0-or-later, source
in `screen/`), `lpac` (AGPL-3.0 / LGPL-2.1, see `licenses/lpac/`), `sha256sums.txt`.

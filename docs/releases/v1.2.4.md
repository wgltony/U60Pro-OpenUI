# v1.2.4 — Remote SSH, Cloudflare IP optimizer, charging animation and guarded IMEI controls / 远程 SSH、Cloudflare 优选、充电动画与受保护的 IMEI 管理

简体中文 · English

## 简体中文

**入口：** 已有安装更新使用 `bash install.sh --update --release v1.2.4`；首次安装见 [本版本安装教程](https://github.com/wgltony/U60Pro-OpenUI/blob/v1.2.4/docs/INSTALL.zh.md)。本版本改动 agent、触摸屏与网页，安装流程与 v1.2.3 相同。

1. **Tailscale 远程 SSH 开关：** 网页与触摸屏的 Tailscale 页新增开关，通过 `tailscale serve` 把 tailnet 的 22 端口转发到本机 SSH；dropbear 本身仍只监听本地。若 tailnet 22 端口已被其他转发规则占用，开关会拒绝而不是覆盖。
2. **通过 tailnet 地址访问网页：** 用路由器的 Tailscale 地址打开网页时，不再报“无法连接 Agent”。agent 会把 tailnet 的 9090 端口转发到自身，并只额外放行路由器自己的 tailnet 地址作为来源。
3. **Cloudflare IP 优选：** 默认开启，Clash 运行时每 4 小时测一次。每个走 Cloudflare 的节点会变成一个回退组：`优选 IP` 优先，原域名兜底。网页与触摸屏都有“立即优选”按钮。
4. **USB 模式一次生效：** 以前切换 USB 模式要点两次。现在三个界面都会显示“切换中”，直到新模式真正出现（约 8 秒）。
5. **充电动画：** 充电时，触摸屏概览与网页首页的电池会显示动画和 ⚡，充满时保持绿色；系统开启“减少动态效果”时网页不播放动画。
6. **受保护的 IMEI 管理（开发功能）：** 网页「信号」与触摸屏信号页进入同一个经过认证、串行化的事务控制器：检查 → 预览 → 两次确认 → 两次手动重启 → 验证，并在写入前保存私有备份。发布文件**不包含**原生 helper，只能通过 `install.sh --from-source --with-imei` 显式安装；没有 helper 时页面显示后端不可用。仅限你拥有或获授权维护的设备，并须遵守当地法律与运营商条款。详见 [IMEI 文档](https://github.com/wgltony/U60Pro-OpenUI/blob/v1.2.4/docs/IMEI.zh.md)。
7. **恢复默认 IMEI：** 在从未进行过任何操作时，第一次“检查”会记录一次默认值（root 私有，绑定 modem，不会改写）。当前值不同时可一键生成回到默认值的预览，之后仍需两次确认和两次重启。
8. **Windows CI 偶发失败修复：** 备份错误密码测试改用固定盐值，不再约 1/256 概率误通过。

**验证范围：**
- agent 301 项单元测试在实机（U60 Pro，B31）上通过；触摸屏全部自测在本机预览中通过；网页 53 项测试、构建、lint、i18n、API 契约与隐私检查通过。
- 实机上验证了：tailnet 9090 转发与 CORS 头、充电状态读取、IMEI helper 完整性，以及 IMEI“检查”（只读）与默认值记录。部署方式是替换组件并保留备份，不是经 `install.sh` 全新安装。
- **未在实机验证：** IMEI 写入、恢复与重启流程从未在真实 modem 上执行；Cloudflare 优选部署时 Clash 未运行，实际优选需由用户自行确认。

## English

**Entry point:** update an existing installation with `bash install.sh --update --release v1.2.4`; for first installs see the [versioned install guide](https://github.com/wgltony/U60Pro-OpenUI/blob/v1.2.4/docs/INSTALL.md). This release changes the agent, the touchscreen and the web panel; installation is the same as v1.2.3.

1. **Tailscale remote SSH switch:** a switch on the Tailscale page (web and touchscreen) forwards tailnet port 22 to the local SSH server through `tailscale serve`. Dropbear itself stays local-only. If another serve rule already holds tailnet port 22, the switch refuses instead of replacing it.
2. **Web panel over the tailnet address:** opening the panel at the router's Tailscale address no longer fails with "cannot connect to Agent". The agent forwards tailnet port 9090 to itself and additionally allows only the router's own tailnet address as an origin.
3. **Cloudflare IP optimizer:** on by default; it runs every 4 hours while Clash is running. Each Cloudflare-fronted node becomes a fallback group: the best measured IP first, the original domain as fallback. Both the web panel and the touchscreen have an "Optimize now" button.
4. **USB mode applies once:** switching USB mode used to take two taps. All three interfaces now show "switching" until the new mode actually appears (about 8 s).
5. **Charging animation:** while charging, the battery on the touchscreen Overview and the web Home page animates and shows ⚡; it stays green when full. The web panel skips the animation when the system asks for reduced motion.
6. **Guarded IMEI controls (development feature):** the web Signal section and the touchscreen Signal page open the same authenticated, serialized transaction controller: CHECK → preview → two confirmations → two manual reboots → verify, with a private backup made durable before any write. Release assets **do not** include the native helpers; they are installed only with an explicit `install.sh --from-source --with-imei`. Without them the page reports the backend as unavailable. Use only on devices you own or are authorized to service, in accordance with applicable law and carrier terms. See the [IMEI documentation](https://github.com/wgltony/U60Pro-OpenUI/blob/v1.2.4/docs/IMEI.md).
7. **Restore default IMEI:** the first CHECK, while no operation has ever existed, records the default once (root-private, bound to the modem, never rewritten). When the live value differs, one tap builds a preview back to the default; both confirmations and the two reboots still apply.
8. **Windows CI flake fixed:** the backup wrong-password test uses a fixed salt, so it no longer passes wrongly about 1 time in 256.

**Validation boundary:**
- All 301 agent unit tests passed on a real U60 Pro (B31). All touchscreen self-tests passed in the native preview. The 53 web tests, build, lint, i18n, API contract and privacy checks passed.
- On the device we checked the tailnet 9090 forward and CORS header, the charging status reading, IMEI helper integrity, and the IMEI CHECK (read-only) with the default being recorded. Deployment replaced components with a backup kept; it was not a fresh `install.sh` installation.
- **Not verified on a device:** no IMEI write, restore or reboot flow has been run on a real modem. Clash was not running when the optimizer was deployed, so a live optimization run is left for the user to confirm.
